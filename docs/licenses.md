# Licenses

This is a commercial product. Everything that ships in the app (code, body models, textures) must
be MIT, Apache 2.0, BSD, ISC or CC0. `node scripts/check-licenses.mjs` enforces this for npm
dependencies and runs in CI.

## Body models: Anny (confirmed)

`public/models/male.glb` and `public/models/female.glb` are generated by `tools/export_bodies.py`
from **Anny** by NAVER LABS Europe.

| Part | License | Source |
|---|---|---|
| Anny code (the generator we run) | Apache License 2.0, Copyright (C) 2025 NAVER Corporation | `LICENSE` in https://github.com/naver/anny (checked at commit `d6fc027`, Sept 2026) |
| Anny `data/mpfb2` (MakeHuman base mesh, targets, rig, UVs) | CC0 1.0 Universal | `src/anny/data/mpfb2/LICENSE.md` in the same repo, "assets adapted from MPFB2 … licensed under CC0 1.0" |
| Anny `data/segmentation` (body part UV mask, used only to drop eye sockets / mouth cavity) | Distributed with Anny under the same terms | same repo |

What we **did not** use:

- **No SMPL / SMPL-X / SMPL+H** or anything derived from them (Max Planck Institute, non-commercial
  research license; commercial use needs a paid Meshcapade license).
- **Not Anny's optional `smplx` / `smpl` topologies.** Anny downloads those from
  `noncommercial.zip` only when you ask for them. The export uses the default `anny` topology; the
  Anny cache used for the export contains no `noncommercial/` files.
- **Not Anny's `soma` topology** (Apache 2.0 from NVIDIA SOMA-X, allowed, but not needed).

What the GLBs contain: the skin surface only, with elbows straightened (our own posing step), (eye backs, eye sockets, mouth cavity and tongue are
removed), positions in meters, smooth normals, Anny/MakeHuman UVs, the original vertex id
(`_VID`), the dominant skinning bone (`_BONE`), and 18 morph targets for Anny's
height/weight/muscle grid. The skeleton JSON has bone names, parents and joint positions for each.

Attribution is not required by CC0 or for Apache 2.0 output data, but we credit Anny and the
MakeHuman community in the app's About text and in this repo as a courtesy. If the Anny code is ever
bundled (it is not; it only runs offline in `tools/`), its Apache 2.0 NOTICE terms apply.

> Not legal advice. Before launch, have counsel confirm the Apache 2.0 + CC0 chain and the
> MakeHuman FAQ position ("models exported from an unmodified MakeHuman are CC0").

`@react-three/drei` was removed in Phase 0: it pulled in `webgl-constants`, which has no license
field, plus many unused modules. We use three.js's own `OrbitControls` instead.
